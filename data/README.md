# Data

**Dataset:** Bank Customer Churn (`Churn_Modelling.csv`): 10,000 customers of a European bank, 14 columns. `Exited = 1` means the customer left.

It's a widely used public dataset. To get it, search Kaggle for **"Churn Modelling"**, download `Churn_Modelling.csv`, and put it in this folder.

The file isn't stored in this repo. The notebook already includes all its outputs, so you can read the full analysis on GitHub without downloading anything.

| Column | Meaning |
|---|---|
| CreditScore | Credit score (350-850) |
| Geography | France, Germany or Spain |
| Gender | Female / Male |
| Age | Age in years |
| Tenure | Years as a customer (0-10) |
| Balance | Account balance |
| NumOfProducts | Number of bank products held (1-4) |
| HasCrCard | Has a credit card (1/0) |
| IsActiveMember | Active member (1/0) |
| EstimatedSalary | Estimated yearly salary |
| Exited | **Target:** left the bank (1) or stayed (0) |
